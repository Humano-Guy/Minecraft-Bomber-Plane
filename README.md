# Minecraft-Bomber-Plane
Schematics for my bomber plane tutorial.


INSTRUCTIONS FOR LITEMATICA ----
Import the files depending on whether you are pasting the build directly in creative (See Bomber_Plane_For_Pasting) or building in survival (See Bomber_Plane_For_Building).

For Pasting ----
This option might not work on later versions of minecraft or litematica. This will not work if any blocks are placed by hand.

For Building ----
Each piston facing a minecart needs a single activation before use. All you need to do is place a redstone block above them, and then remove it. You should see that the slime blocks move into place. Any activation after this point will drop TNT like it should when activated.


For Using ----
At the back of the center of machine there are two pistons stacked on top of each other, the higher being one block ahead of the lower. To activate the machine please place any block in front of the higher observer. To stop the machine, you can place an immovable block (obsidian/furnace) in front of the machine. Do not start using this until all pistons have been activated as mentioned in the [For Building] section. For any other information, please refer to the video tutorial.
